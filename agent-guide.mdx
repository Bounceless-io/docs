---
title: "Agent onboarding"
description: "Install the Bounceless skill for a coding agent."
---

Install the raw skill from the documentation origin:

```bash
npx skills add https://docs.bounceless.io
```

Then provide `BOUNCELESS_API_KEY` through the agent runtime's secret environment. The skill explains how to choose API, MCP, or CLI, including single verification, batch polling, results, and a safe smoke test.
