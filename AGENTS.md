# Documentation project instructions

This is the public Bounceless documentation site on Mintlify.

- Pages are MDX files with YAML frontmatter
- Configuration lives in `docs.json`
- The installable agent skill is `skill.md`
- The GA HTTP contract is `openapi.yaml` (four routes only)
- Playground pages live under `api-reference/` and must not prefill or persist API keys
- Do not document private backend or engine internals
- Do not expose product API endpoints as Mintlify tools
