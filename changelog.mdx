## 2026-09-07

- Reworked onboarding from account creation to API key and first request.
- Documented the single-verification `202` limit, the additive `presend` compatibility envelope, decisions, reason codes, credits, and bounded retries.
- Made cursor pagination canonical while retaining offset compatibility.
- Replaced the unsupported CLI wait example with `submit`, `status`, and `results` commands and explicit JSON/CSV redirection.
- Made the published batch export fail closed on HTTP or JSON errors, use bounded retries, and replace its final file only after complete cursor pagination; CI now executes that exact MDX fragment.
- Moved the human MCP guide to `/guides/mcp`; `/mcp` remains reserved for Mintlify's documentation transport.
- Added the developer-tools 1.0 migration, an integrator-first repository README, contribution paths, and Bounceless visual identity.

<Note>This entry records documentation published on docs.bounceless.io. It does not announce a new npm package version; confirm registry availability before following version-specific CLI or MCP guidance.</Note>
