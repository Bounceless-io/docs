# Security

This repository is the **public** source for [docs.bounceless.io](https://docs.bounceless.io).

Do not commit secrets, credentials, customer data, cryptographic keys, or environment files.
Do not add GitHub Actions secrets to this repository.

Report suspected secret exposure or a documentation-site vulnerability through
[GitHub private vulnerability reporting](https://github.com/Bounceless-io/docs/security/advisories/new).
Do not open a public issue containing exploit details, credentials, or private data.
