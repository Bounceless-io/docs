---
title: "Quickstart"
description: "Make your first verification request."
---

Set your key locally and keep it out of source control:

```bash
export BOUNCELESS_API_KEY="blc.your_key"
```

```bash
curl --request POST https://api.bounceless.io/v1/verify \
  --header "X-Api-Key: $BOUNCELESS_API_KEY" \
  --header "Idempotency-Key: quickstart-001" \
  --header "Content-Type: application/json" \
  --data '{"email":"test@example.com"}'
```

A completed request returns `200`; work still running returns `202`. Store the response `requestId` for support and observability.

<Note>The interactive API playground asks you to paste a key for the current request. This documentation never pre-fills or persists it.</Note>
